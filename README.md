# Personal website

Built with [solid-static](https://github.com/meoyawn/solid-static), the best static site generator.

Tooling uses [Aube](https://aube.sh) 2.5.1 and [Task](https://taskfile.dev).
Aube reads the pinned Node.js version from `.node-version`.

Run `aube install` to install dependencies, `task dev` to develop locally, and
`task check` to run linting, type checking, unit tests, and build E2E tests.
